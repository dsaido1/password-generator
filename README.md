# 🔐 Password Generator

A simple command-line tool that generates secure, random passwords using Python's built-in `random` and `string` modules.

---

## Features
- Generates a random password using letters, digits, and punctuation
- User-defined password length
- Length validation (must be between 6 and 15 characters)
- Handles invalid input gracefully without crashing

---

## How it works
1. Run the script
2. Enter your desired password length (6–15)
3. A random password is generated and displayed

---

## Example

Enter the length of the password: 10
Your password is: T7$kLp9#zW


---

## Requirements
- Python 3.10+
- No external libraries — uses only Python's standard library (`random`, `string`)

---

## Run it

```bash
python password_generator.py
```
